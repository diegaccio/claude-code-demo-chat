## BDG skills

- BDG skills configuration (Issue tracker, Code host, task workflow, domain docs): `docs/agents/README.md`. Read the file it names before touching Issues, pull requests, labels or the glossary.
- When a BDG skill (`bdg:*`) misbehaves or could work better, propose opening an Issue on `bdg-agent-skills` (on Base Digitale's GitLab; ask the user for the link) with the skill, what happened and what you expected; open it only if the user agrees.
- When a change adds tooling that could become a Validation step (a test runner, a linter, a build or setup script), propose running `bdg:validation-setup` to update `docs/agents/validation.md`.
