# Glossary

The domain language of this project. Use these terms in code, tests, Issues and docs; avoid the synonyms listed under _Avoid_.

**Demo app**:
This terminal chat, which answers from a model.

**Model profile**:
A named setting that tells the Demo app which model server and model to use: the local one or SRH.
_Avoid_: backend, provider, endpoint

**SRH**:
Base Digitale's shared prototype machine, serving larger models over an OpenAI-compatible API.
_Avoid_: AI server

**Persona**:
A named system prompt that `/persona` switches to.
