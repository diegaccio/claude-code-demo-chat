# Agent configuration

Configuration the BDG skills read in this project, one file per concern. Written by `bdg:bootstrap`; edit any file by hand, and re-running bootstrap keeps the edits.

| File | Read it before |
| ---- | -------------- |
| `docs/agents/issue-tracker.md` | creating, reading, labelling, linking, assigning or closing an Issue. |
| `docs/agents/submission.md` | opening or updating a pull request, or choosing its reviewers. |
| `docs/agents/task-workflow.md` | choosing a Task's type, state or label, or moving it to another state. |
| `docs/agents/domain.md` | naming a domain concept, or reading or writing the glossary or an ADR. |
| `docs/agents/team-map.md` | choosing an assignee, a dialogue counterpart or a reviewer, or identifying the current user's role. |
| `docs/agents/validation.md` | running, changing or reporting on the Validation steps, or calling a change green. |
| `docs/agents/model-routing.md` | rating a Task's Tier, or spawning a subagent: the model of each Tier and fixed role. |
